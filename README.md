## Current Engineering Work

### CS400 - IoT-Based Solar DC Load Management System

My final-year Computer Engineering project focuses on managing low-voltage DC loads in a solar-battery system.

The system combines:

- ESP32 central and smart nodes
- INA219 voltage, current and power sensing
- Relay-based load control
- ESP-NOW communication
- MQTT telemetry
- Battery and available-power monitoring
- An adapted Best-First Search algorithm for load scheduling

The scheduling logic considers available power, battery condition, user priorities, startup demand and electrical constraints before deciding which controllable loads can operate.

### Client Computer-Vision Project

I am developing parts of a CPU-based real-time video-analysis pipeline using **Python, OpenCV, MediaPipe, DeepFace and YOLO**.

The system combines observable cues such as facial expression, eye gaze, head pose, posture, person detection and presence/attention events. Higher-level behavioural states are implemented as heuristic interpretations of observable signals rather than psychological or clinical diagnoses.

Repository: [engagement-monitor](https://github.com/SilasChalwe/engagement-monitor)
